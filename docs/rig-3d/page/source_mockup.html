Whether a component is wearing out. Drift in a channel is a description of the channel, not of the hardware behind it — a rising noise floor is equally consistent with a loose connector, a warming sensor, or a change in how hard the pedal is being pressed. There is no channel that separates them, so this page reports the drift and stops there.
